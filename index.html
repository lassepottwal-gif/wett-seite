☁ Online-Synchronisierung

Damit alle denselben Spielstand sehen, verbinde Punktspiel mit einer gemeinsamen Firebase Realtime Database. Die HTML-Datei kann weiterhin über GitHub Pages veröffentlicht werden. Trage für alle dieselbe Datenbank-URL und denselben Spielschlüssel ein.

Noch nicht verbunden. Lokale Speicherung ist aktiv.

Wichtig: Stelle die Datenbankregeln passend ein. Eine öffentlich les- und schreibbare Datenbank kann von Fremden verändert werden. Für echte Zugriffskontrolle braucht es Firebase Authentication und passende Regeln.

🗑 Papierkorb des Wettverlaufs

Hier findest du gelöschte Verlaufseinträge. Wiederherstellen bringt sie zurück. Gelöschte Einträge ändern keine Punktestände.

💾 Spielstand sichern

Exportiere eine Sicherung als JSON-Datei oder importiere sie auf diesem Gerät. Das ist noch keine Live-Synchronisierung zwischen Geräten.

🔄 Spielstand zurücksetzen

Entfernt alle Teilnehmer, Wetten und Verlaufseinträge von diesem Browser.
