☁ Online-Synchronisierung

Damit alle denselben Spielstand sehen, verbinde Nexus Bets mit einer gemeinsamen Firebase Realtime Database. Die HTML-Datei kann weiterhin über GitHub Pages veröffentlicht werden. Trage für alle dieselbe Datenbank-URL und denselben Spielschlüssel ein.

Live synchronisiert über Firebase. Jackpot und tägliche Quests liegen im selben gemeinsamen Spielschlüssel.

Wichtig: Stelle die Datenbankregeln passend ein. Eine öffentlich les- und schreibbare Datenbank kann von Fremden verändert werden. Für echte Zugriffskontrolle braucht es Firebase Authentication und passende Regeln.
